# Crouzeix Conjecture Prompt · 中英双语整理

这是对 [jinshanmu/CrouzeixConjecture](https://github.com/jinshanmu/CrouzeixConjecture) 仓库中 `crouzeix_conjecture_prompt.txt` 的中文双语整理。

这个仓库把原始 prompt、可直接在 GitHub 网页阅读的双语 Markdown、以及中英双栏 PDF 放在一起，方便读者快速了解它如何把一个数学证明题包装成“多智能体、持续搜索、对抗审查”的证明搜索任务。

## 内容范围

原始 prompt 的数学部分要求证明一个关于复矩阵数值域、算子范数和多项式函数演算的命题；后半部分则规定了证明搜索的组织方式，包括多样化路线、方法族登记、对抗性审查、失败路线标记和持续迭代。

这里的 PDF 和 Markdown 是阅读整理，不是对该数学命题的证明，也不对任何模型生成的“完整证明”作正确性背书。原始英文 prompt 以独立文件保留，便于逐句对照。

## 来源

原始文件：<https://github.com/jinshanmu/CrouzeixConjecture/blob/main/crouzeix_conjecture_prompt.txt>

本仓库只整理 prompt 的公开文本和双语阅读材料；数学命题本身的真伪、历史状态和任何后续证明，应以独立的数学文献与逐行审查为准。
